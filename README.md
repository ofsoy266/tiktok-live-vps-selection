## 机房 IP、原生 IP、住宅 IP、双 ISP，这四个词说的不是一回事

TikTok 的风控不看你的 CPU 有几个核，它看这台机器在平台眼里像什么。

数据中心 IP 的 ASN 属于云服务商或 IDC，同一段地址里常年跑着爬虫、批量注册和自动化工具，被反复标记。用这类 IP 开播，画质被压到 480p、推流被掐断、账号权重一路走低，是做直播的人反馈最多的一类问题。

原生 IP 指 IP 的注册归属地和服务器物理位置一致，中间没经过转发或伪装。服务器在洛杉矶，IP 注册地也在美国，这就是原生。

住宅 IP 看的是 IP 的持有者。它属于住宅宽带运营商，而不是机房托管商。

双 ISP 指一台服务器同时具备两个 ISP 的认证属性，在 IP 检测工具里会显示成家庭宽带特征。三者叠加起来，才是常被推荐的“双 ISP 住宅原生 IP”。

原生 IP 和住宅 IP 是两件独立的事。一个 IP 可以归属地完全正确、是标准的原生 IP，ASN 却仍然是机房，风控照样认得出。很多文章把这两个概念混着写，读者买完才发现自己拿到的是“机房里的原生 IP”。

## 带宽要买多大：3Mbps 和 500Mbps 之间差的是什么

| 直播场景 | 推荐上传带宽 | 分辨率 |
| --- | --- | --- |
| 手机单账号直播 | 3–5 Mbps | 720p |
| OBS 单路推流 | 6–8 Mbps | 720p–1080p |
| OBS 1080p 高清推流 | 10–15 Mbps | 1080p |
| 3–5 个账号矩阵 | 30 Mbps 以上 | 1080p |

不同来源给出的数字有出入，有的写“1080p 推流码率 3–6Mbps 就够”。那说的是平台默认码率下的单路推流；用 OBS 手动把码率拉到 10–15Mbps，画质更干净，上行占用也更大。两个口径不冲突，取哪个看你的推流设置。

真正会让直播卡住的地方在跨境回程。晚高峰时段国内到海外机房的丢包和抖动，对观感的影响远超带宽数字。同样是 100Mbps，走 CN2 GIA、CMIN2、9929 这类优化线路的机器，和走普通国际出口的机器，推流稳定性差得明显。预算有限时，先保线路，再谈带宽。

流量额度也值得看一眼。Akile 多数套餐在流量超限后限速 10Mbps 而不是直接停机，这个设计对直播友好：按 3–6Mbps 的单路码率算，限速后还能继续推一路 1080p，只是没法再开 OBS 高码率。英国 UK Lite2 的流量重置价格是 14 元/TB，用超了补起来不贵。
